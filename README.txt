ОЖИВАЕТ — обновлённый сайт для Cloudflare Pages (Direct Upload).

1. Откройте Cloudflare Dashboard → Workers & Pages → Create → Pages → Direct Upload.
2. Загрузите ZIP-архив или папку сайта.
3. После публикации проверьте сайт на телефоне, цены и кнопки Telegram / MAX / Instagram.

Особенности:
- Нет портфолио, клиентских обложек и видео.
- Семь этапов создания фильма, новые изображения, раздел автора.
- Заявки направляются в мессенджеры, не сохраняются на сайте.
- Подсказку для заказа можно скопировать; сообщение автоматически не отправляется.
- Цены поздравлений и историй любви являются ориентировочными.
- Скидка 15% рассчитана от базовых цен, предоставленных ранее.
- Авторский портрет оформлен как созданная иллюстрация, не документальная фотография.
